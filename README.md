# Mamelao's Seedchecker

## Tool to speedup checking seeds

This mod loads a list of seeds which lets check seeds even faster.

* No more manual searching

## How to use

Download the mod by clicking release on the right, and following this tutorial:
www.youtube.com/watch?v=RpN94a2q8JI

In the mods folder put the .jar file you installed (you should also have fabric api) <br>
Click i (can be changed) to load the next seed in the list. <br>
Put the seeds in .minecraft/config/mamelaos-seedchecker/seeds.txt <br>
Every time you load a seed it gets removed from seeds.txt

### Commands

You can put a list of commands to run when entering a world. Put them in commands.txt but remember to write them without slashes <br>
Full path is .minecraft/config/mamelaos-seedchecker/commands.txt<br>
